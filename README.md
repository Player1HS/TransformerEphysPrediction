# TransformerEphysPrediction

The code for all the tests conducted in the study is contained within the "Human" folder. Within it, there exist "w_types_comparison", "wo_types_comparison", "celltypeinitialized_comparison", and "DualMLP" folders which contain the code corresponding to their respective tests. There is also the "Data Preprocessing" folder which has the code yielding the .h5ad and pickled electrophysiology dataframe used for all the aforementioned downstream tests. The "onefeaturepermlp" folder was used to make some supplementary information.

There is also an environment.yml file for the Conda environment used.
